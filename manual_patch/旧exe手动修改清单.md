# 旧 exe 自己改：到底改哪几处

> 核对方式：把 `E:\ds-trim-gateway-release\ds-trim-gateway-release\ds-trim-gateway.exe`
> 里的 Python 归档拆开，逐个比对界面代码与网关代码。
> **结论：界面、图片识别、网关代搜这些代码，旧 exe 里都是新的；唯一落后的是它内部
> 写死的「客户端预设」**（5 个工具、669 字提示词、1500/3000/8000 精简参数、搜索模式 on）。

所以不需要改代码，只需要在界面上改 **3 个页签、5 个必改值**（另有 3 个可选）。

> 实测证据（`verify_old_exe_cfg.py`，把旧 exe 里的 gateway_core 单独跑起来）：
> 配置里放 7 个工具 → 旧 exe 读出 7 个 → `Write`/`Edit` 都进了发给上游的工具清单 →
> `<invoke name="Write">` / `<invoke name="Edit">` 都能正确解析成 tool_calls →
> 回填客户端不告警。也就是说**旧 exe 完全能驱动 Write/Edit，缺的只是预设里没有**。

| 5 | 上下文精简 | `工具历史总字符预算` | `history_total_chars` | 8000 | **24000** |

## 三、操作顺序

1. **先备份**：把 exe 同目录的 `config.json` 复制一份（`config.json.bak-manual`）。
2. 双击 exe → **提示词**页 → 点进文本框 `Ctrl+A` 全选删除 → 打开
   `粘贴-1-提示词.txt` 全选复制粘贴进去。
3. **工具 (JSON)** 页 → `Ctrl+A` 全选删除 → 粘贴 `粘贴-2-工具JSON-完整7条.json`。
   （只想手工插两条的话，用 `粘贴-3-只补Write和Edit.json`，插在 `Glob` 后面。）
4. **上下文精简**页 → 改两个数字：`单条结果截断字符` 3000→**8000**、
   `工具历史总字符预算` 8000→**24000**。
5. 顺手回到**提示词**页，把提示词框正下方那一行的 `system 最大字符数` 改成 **2000**
   （它管的是这段提示词本身允许多长，和新提示词 1195 字配套；不在上下文精简页！）。
6. 点底部 **保存配置** → 状态栏出现「网关热重载」即生效，**不用重启网关、不用重启客户端**。
7. 复核：打开 exe 同目录 `config.json`，确认 `"tools"` 里有 7 个 `name`，
   且 `history_result_chars` 是 8000、`max_system_chars` 是 2000。

## 四、三个雷区（这就是「改完又变回去」的真正原因）

旧 exe 的内置预设是编进 exe 里的旧版，只要碰到下面两个按钮，工具和提示词立刻被打回 5 条：

1. **切客户端**（下拉切到另一个客户端）—— 会弹窗问「是否用预设覆盖当前内容？」，
   一定选 **否**（选「是」= 回到 5 工具 + 669 字提示词）。
2. **恢复默认精简参数**（在上下文精简页底部）—— 会把 `3000 / 8000` 这几个历史参数打回
   1500/3000/8000 那套旧值。注意它**不碰** `system 最大字符数`（那一格在提示词页），
   所以 2000 是安全的，被打回的是 `单条结果截断`（3000）和 `工具历史总预算`（8000）。
3. 重新解压/替换 exe 到新目录再双击 —— 会重新生成一份旧默认 `config.json`。

这三处是**改不掉**的（要改只能换 exe）。日常只要不碰，配置会一直保持。

## 五、4 轮的坑

`保留最近轮数 = 4` 加 `单条截断 = 8000` 就是 32000 字，超过 `工具历史总字符预算 24000`，
最早一轮会被丢掉，等于白设。

- 想真留 4 轮 → 总预算填 **32000**（代价：更接近上游长上下文风控）。
- 想稳 → 轮数填 **3**（3×8000=24000，正好装满）。

## 六、这些**不用**改（旧 exe 已具备）

- 图片 `@` 路径识别（token 切分、尾部标点剥离、runtime 噪声行过滤）：旧 exe 里都有。
- 网关代搜（`server_search.py` + 代搜接线）：有，只是默认值不同。
- docx 读取、pptx 生成：属于**提示词级**能力，第 8/9 条写进提示词就能用，不需要改代码。
- 新界面（副标题「AFS 套件之一」、5 页签、日志页、模型列表）：都已经是新的。
