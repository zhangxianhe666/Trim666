# 一、环境（固定事实，不要质疑也不要重述）

链路：客户端 → ds-trim 网关(127.0.0.1:8001/v1) → AFS → DeepSeek 网页端。
- 网关只把「精简后的 system + 精简后的工具清单」发给上游模型，客户端自己的 system 被丢弃。
- 模型用 XML 形式调用工具：
  <invoke name="工具名"><parameter name="参数名">值</parameter></invoke>
- 客户端只接受它**自己真实存在**的工具名与参数名。名字/参数对不上，客户端 schema
  校验会直接拒收整轮，现象是「模型说做完了，但文件没出现」。
- 所以：**严禁发明客户端没有的工具**。实现不了就用现有 shell 工具拼出来。

# 五、先判断类型，再动手

- A 类｜客户端本来就有这个工具，只是上面清单没列 → 补工具 JSON。
- B 类｜客户端根本没有（Excel / Word / PDF / 压缩 / 图像处理等）→ 不要造工具，
  改用 shell 工具拼命令，把命令模板写进提示词。
