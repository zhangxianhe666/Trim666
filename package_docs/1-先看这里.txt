ds-trim-gateway 绿色包 · 第一次使用（Windows）
==============================================

一句话说清楚
------------
这不是"装完登录就能用"的软件。它是一个**转发层**：

    你的客户端(DSH / WorkBuddy)  →  网关(8001)  →  AFS(8080)  →  DeepSeek

- AFS（同目录 AFS\AFS.exe）才是真正持有账号、能连 DeepSeek 的那一层；
- 网关只做三件事：把长上下文精简后转发、把 DeepSeek 返回的 XML 转成标准工具调用、
  在客户端搜索不可用时替它搜网页。

所以：**两个程序必须一起跑，缺一个都不行**。exe 本身不含任何账号或额度。


解压到哪
--------
解压到 D:\ 或桌面这类普通目录。不要放：
- C:\Program Files  —— 需要管理员权限，配置存不进去，网关起来就报错
- OneDrive / 微信接收目录 —— 同步会锁文件
路径尽量别带空格（D:\trim 就挺好）。


三步上手
--------
第 1 步 · 启动 AFS
  双击 AFS\AFS.exe，在它自己的窗口里登录**你自己的** DeepSeek 账号。
  （别人的账号不吃你的额度，每个人必须用自己的，这点绕不过去。）

  确认它起来了：浏览器打开 http://127.0.0.1:8080/health ，返回 ok 即可。
  这个窗口不要关。

第 2 步 · 启动网关
  双击 ds-trim-gateway.exe
    (1)「基础」页：客户端选 DSH 或 WorkBuddy
        —— 这一步决定工具名，选错就等于模型拿到了不存在的工具，什么也调不动
    (2)点「保存配置」
    (3)点「启动网关」，状态变成「运行中 · http://127.0.0.1:8001」就好了
  窗口不要关（关掉 = 网关停止）。

第 3 步 · 把客户端指过来
  照 2-客户端接入.txt 改一处地址。


怎么确认真的通了（建议按顺序做）
--------------------------------
1) 浏览器打开 http://127.0.0.1:8001/health
   看到 {"status":"ok","upstream":"http://127.0.0.1:8080/v1"} 说明网关在跑且指向 AFS。
2) 全链路自检：先关掉网关界面，在这个目录开命令行执行
       ds-trim-gateway.exe --selftest
   会在同目录生成 selftest-result.txt，出现 PASS 表示 /health、/v1/models、
   一次真实对话全部通过。
3) 客户端里先问一句不需要工具的（比如"你好"），能答说明通道通了；
   再让它"查一下今天重庆天气"，验证工具调用与代搜。


常见问题
--------
· 启动网关报端口占用
  已经有一个在跑了。任务管理器结束所有 ds-trim-gateway.exe 再启动。

· 对话一直转圈 / 空回复
  上游没起来。先确认 AFS 窗口还开着，再打开 http://127.0.0.1:8080/v1/models
  能不能看到模型列表。

· 报 503 No available account for model
  模型名和 AFS 里的对不上。复制 /v1/models 里的 id，粘到网关「基础」页的模型名，
  必须一字不差（大小写、连字符都算）。

· 工具调不动（不读文件、不搜索、列不出目录）
  客户端选错了。DSH 选 DSH、WorkBuddy 选 WorkBuddy，「保存配置」后重启网关。

· 图片看不了
  1) 图片必须在这台电脑的硬盘上（AFS 读本地文件再上传）；
  2) 客户端的「图片输入 / supportsImages」要关 —— 关掉后它才会把本地路径发过来，
     网关据此读盘送图；开着它反而可能把图片丢弃。

· 网络搜索没结果
  网关「上下文精简」页 → 搜索：自动（推荐）/ 总是代搜 / 关闭。
  客户端自带的搜索是拿客户端自己的 Key 直连 DeepSeek 的，Key 失效时它一定失败，
  这时让网关代搜即可。

· 任务超出内置的 7 个工具（要处理 Excel / Word / PDF / 批量改图…）
  内置工具只有：shell、读文件、找文件、写文件、改文件、搜索、抓网页。
  更复杂的活照 3-扩展工具与提示词.txt 操作：把任务填进那份模板，交给任意会写代码的
  AI，它会告诉你要加什么工具、提示词该追加哪几条，你照抄进去即可。

· 双击没反应 / 一闪就退
  同目录会生成 launcher-error.log，把它和你做了什么一起发给发给你的人。


给别人之前请注意（分发者看）
----------------------------
· 只发这一个 zip 就行，里面 exe 和 config.json 是配套的，别只发 exe
  （单独一个 exe 会回落到默认配置：空 Key + 本地 8080 + DeepSeek-V4.1-Flash，
   在没装 AFS 的机器上必然连接失败）。
· 别把 %APPDATA%\chat2api 一起发出去 —— 那是 AFS 的登录状态和 Cookie，
  里面是你自己的账号。
· 对方只需要有：这个包 + 一个能用的 DeepSeek 账号。
